# SPD34-Link firmware updates

Public distribution metadata for the SPEEDE34 Android app. Source code is maintained separately.

The signed catalog is initially empty: no firmware is published or promoted automatically.
Stable and beta channels are selected in the app; notification and installation are opt-in.
Firmware artifacts must be signed, compatible with the identified hardware, and reviewed before publication.
No private signing keys, credentials, source trees, or vehicle data belong in this repository.
